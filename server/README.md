# Vera room server

`signaling_server.py` is a dependency-free Python WebSocket room server for Project Vera. It is the only runtime service needed for the automatic room-code multiplayer mode; the game frontend remains a static GitHub Pages deployment.

## Local / LAN

Start it from the repository root:

```powershell
python server/signaling_server.py --host 0.0.0.0 --port 8765
```

Open the frontend with the server URL in the query string:

```text
http://localhost:4173/?signal=ws%3A%2F%2F127.0.0.1%3A8765
```

For another computer on the same Wi-Fi, replace `127.0.0.1` with the host PC's private address, for example `192.168.1.25`. Allow the selected port through the host PC firewall if Windows prompts for it.

## Public / GitHub Pages

GitHub Pages cannot run this Python process. To make a room reachable outside the host network, expose the process through a public DNS name and a TLS endpoint, or put it behind a trusted TLS reverse proxy/tunnel. The HTTPS frontend must connect with `wss://`; browsers block `ws://` from an HTTPS GitHub Pages page.

Direct TLS termination is supported when a certificate and private key are available:

```powershell
python server/signaling_server.py --host 0.0.0.0 --port 443 --certfile C:\certs\fullchain.pem --keyfile C:\certs\privkey.pem
```

Then open:

```text
https://entrenchedosx.github.io/cs2web/?signal=wss%3A%2F%2Fvera.example.com%2Fsignal
```

Do not commit private keys. If a router forwards a public port to the Python process, forward it only to the intended host PC and keep the process updated.

## Protocol and limits

- WebSocket path: `/signal`
- Health check: `/healthz`
- Room codes: six characters, generated by the server
- Capacity: 20 total players per room
- Actions: `create`, `join`, `state`, `control`, `leave`
- Binary player state is base64-wrapped only because the WebSocket envelope is JSON; the server validates packet size and broadcasts it to the room.
- Control messages are size-limited and malformed JSON/messages are ignored or rejected without crashing the server.
- Closing the host closes the room and notifies all guests.

This is a small room relay, not an anti-cheat authoritative simulation service. The existing client keeps local input responsive and interpolates remote snapshots; future server authority can be added behind the same room protocol.
